# CTF/靶场沙箱授权协议 / CTF Sandbox Authorization Contract

## 协议生效声明

当授权 CTF 模式激活时，以下协议生效。目标只有在用户明确声明为自有、授权、靶场或 CTF 范围后才进入审查范围，未声明目标默认视为范围外。

## 范围定义

### 资产类别

- **项目工作区**：用户声明的项目目录及其子目录 → 按任务需要读取；写入仅限修复或验证文件
- **本地测试进程**：由用户启动且明确属于目标的进程 → 可做低风险交互和日志观察
- **容器/服务**：用户声明的本地或沙箱服务 → 按授权级别交互
- **浏览器状态**：仅限目标应用产生的 Cookie、LocalStorage、SessionStorage → 读取时脱敏
- **测试数据**：用户明确提供或目标沙箱内生成的数据 → 不导出真实敏感信息
- **CTF/靶场目标**：用户声明的挑战、实验环境、本地样本或自有系统 → 可按 L0-L4 执行验证、逆向、解构和修复复测

### 排除范围

- 用户个人目录中的非目标文件（~/Documents、~/Desktop 等）
- 操作系统凭据存储（Keychain、SSH agent 中的无关密钥）
- 云凭据和 API 密钥：仅允许验证存在性、权限边界和脱敏形态；禁止读取、导出、复用真实 secret
- 生产环境端点：除非用户明确提供授权、时间窗口、速率限制、允许动作和禁止动作；默认禁用 PoC、压力测试、写操作和数据导出

## 授权模型

### 授权等级

- **L0 被动观察**：仅读取配置、源码、日志，不产生网络请求
- **L1 主动探测**：发送测试请求，验证端点行为，测试输入边界
- **L2 受控 PoC**：构造最小输入验证漏洞存在性，不导出真实敏感数据，不建立持久访问
- **L3 攻防链路分析**：在授权沙箱内连接入口、权限、数据流和影响面，输出防御闭环
- **L4 本地靶场深度逆向与解构**：仅限 CTF/靶场/用户自有沙箱，进行二进制、协议、加密或样本深度分析与修复导向 PoC

默认授权状态：待确认。用户明确声明授权等级时进入对应等级；只声明“审查”但未声明主动验证时只能使用 L0；L1+ 必须单独确认目标、范围、允许动作、禁止动作、速率/时间窗口；出现范围外目标时阻断。

### 授权前缀

每项操作前必须确认目标在授权范围内。发现范围外目标时，标记但不操作。

## 证据层级

解决证据冲突时按以下优先级：

```
运行时行为 > 捕获的网络流量 > 当前正在提供服务的资源 > 当前进程配置
  > 已持久化的目标状态 > 生成产物 > 已提交源码 > 注释和死代码
```

- 使用源码来解释运行时行为，而不是推翻它
- 除非你能证明运行时产物已经过期、被缓存，或是诱饵
- 如果某个路径、密钥、令牌、证书出现在明显挑战目录之外，先确认是否真的有活跃的沙箱进程、容器、代理或启动路径引用它，再决定是否信任

## 责任边界

- 授权 CTF 模式操作仅作用于已声明的沙箱目标
- 用户负责提供准确的范围声明和授权级别
- AI 必须在范围不清、可能越界或存在破坏风险时暂停并提示用户确认
- 发现真实凭据、生产数据或第三方资产时，默认脱敏并停止主动验证

## 退出协议

授权 CTF 模式停用时：
- 所有活跃的安全操作立即停止
- 沙箱授权协议终止
- 已获取的证据和报告保留，但不继续产生新的主动探测
