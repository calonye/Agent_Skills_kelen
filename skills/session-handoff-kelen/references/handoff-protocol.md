# 会话连续性与交接执行协议

## 目的

以分级持久化保障会话连续性：真实会话结束留下轻量日志；仅当需要续接、需要形成可跨会话持续材料的压缩/恢复治理或明确详细记录时生成交付物；单纯压缩整理或恢复抽查可以只输出结果。

## 术语

- 会话（session）：宿主管理的一段主上下文生命周期，可被结束、压缩、恢复或替换为新会话；结束时生成轻量日志。
- 对话（turn / exchange）：同一会话中的消息往返，不因一次回复结束或普通收尾自动生成交付物。
- 详细交付物：为续接、需要持久化的新恢复状态或显式详细记录生成的结构化材料，不与结束日志混同。
- 子 Agent 上下文：主会话分派的独立执行上下文，记录与主会话分离，并仅在详细交付范围与授权允许时建立关联。

## 触发证据

按处理模式判定：
1. 用户明确正在结束当前真实会话，或宿主提供已验证的会话结束事件 → `end_log`；结束证据未知时不得落盘。
2. 用户明确要求接力、换会话继续、生成详细交付物或记录子 Agent 结果 → `detailed_handoff`。
3. 宿主明确发出压缩/上下文压力信号且存在连续性风险 → `compression_hygiene`；若未完成任务需要延续，同时进入 `detailed_handoff`。
4. 用户要求继续之前的工作、恢复上下文或核对交付物，或宿主提供恢复信号 → `restore_verify`。
5. AI 仅感觉上下文可能不足，但宿主未提供事实信号 → 只能建议，不得记录虚构百分比。

同一会话内的普通问答结束或普通进度汇报不触发写入。真实会话结束但不存在续接目的时，仅写轻量结束日志，不创建详细交付物。

自动触发边界：
- 用户表达“结束这个会话”“换会话继续”“恢复上次工作”等口语时，已安装 skill 的语义触发可执行本协议。
- 无用户消息的 `SessionEnd`、压缩或恢复事件只有在宿主事件路由已验证能够调用本协议或等价执行入口时，才可声明自动执行；仅安装 skill 不构成事件触发证据。

## 优先级

- 用户对本次交付的明确要求优先于默认行为。
- 已生效的全局或项目规则优先于本 skill 默认目录与格式。
- 宿主自带的上下文管理预设优先于自造阈值。
- 规则冲突改变存储位置、隐私范围或内容删减时，先提出澄清。
- 高优先级规则无条件要求每次会话产生详细交付物，但只需要结束记录时，标记 `rule_conflict: upstream_unconditional_policy`；该冲突应收敛为轻量日志 + 条件式详细交付。

## 决策前推理闸门

需要澄清、授权或裁定时，先执行“推理/思维链基本要求”的可审计版本：目标重述 → 信息与证据检查 → 不确定性识别 → 反方风险 → 最小决策。输出只包含目标、证据缺口、风险和裁定依据，不输出完整隐藏思维链。

选项规则：
- 互斥选择必须标 1 个推荐项，并给出一句核心逻辑理由。
- 多选可标推荐组合，并说明每个选项的取舍影响。
- 证据不足时不强行推荐，先标明缺口和需要用户确认的范围。

## 架构解耦与研发记录

公共规则包只承载协议、模板和边界；真实会话记录、项目路径、附件引用和执行状态只进入授权研发文档根目录。详细交付物、子 Agent 记录、附件索引和 ISON 导航必须分文件或分区承载，避免把全部内容堆进单一正文。

写入前记录 `pre_record_basis`：处理模式、目录依据、授权范围、架构边界和待排除内容。写入后记录 `post_record_verification`：实际路径、索引关系、授权状态、排除内容和残余风险。缺少前后记录时，不得声明交付物已完成。

## 轻量结束日志

结束日志用于证明会话已结束和定位后续资料，不承担详细交付功能。写入前必须取得 `user_closed` 或 `verified_host_session_end` 证据；证据未知时返回阻断或不需要写入。只写：会话标识、非敏感主题标签或 `redacted`、结束原因或可观察信号、结束状态、详细交付物引用（若存在）、未解决风险是否存在、验证状态和更新时间。

不得写入：完整对话、详细思路、未授权摘要、完整提示词、子 Agent 原文、附件内容或敏感数据。

## 详细交付内容模式

### 默认：引用导航

记录事实定位与继续入口：
- 目标、范围、禁止事项。
- 已完成结果及验证证据的引用位置。
- 待做事项、阻塞、风险、下一命令或下一检查。
- 子 Agent 任务与结论引用。

不重新叙述完整思路，不自动压缩用户内容。

### 授权后：脱敏摘要

只有用户明确同意摘要，或权威规则明确授权时启用。摘要必须：
- 标记 `summary_mode: authorized_redacted`。
- 去除密钥、个人线索、完整提示内容和无关对话。
- 区分事实、推断、待确认和已排除内容。

### 无价值信息过滤

这不是摘要授权，而是质量过滤。生成交付物或宿主进行压缩时，可排除：
- 失败且未产生新证据的工具调用。
- 重复且未产生新结果的尝试。
- 已被用户或证据明确纠正的错误路径。

不得排除：
- 用户最终裁定与授权。
- 失败原因中仍会影响下一动作的证据。
- 未解决风险和需要复验的异常。

## 子 Agent 与附件

- 默认保存子 Agent 的任务范围、输入读取/调用授权、输出目标、最终结论和脱敏证据引用。
- 完整任务提示、完整结果原文、截图或其他附件需要逐次授权。
- 附件索引需写明归属会话、归属 Agent、授权状态、内容类型和相对路径。
- 结束日志与交付物的目录索引只保留最小导航字段；主题字段默认为非敏感短标签或 `redacted`。

## 恢复校验

- 读取结束日志或交付物时，将其视为待核验的导航线索，不作为事实终点。
- 影响下一动作的完成项或验证声明，抽查 1-2 项可复现证据；结果记录为 `verified`、`partial` 或 `pending`。
- 只有在恢复后需要形成新续接状态或用户要求更新详细材料时，才新建详细交付物。

## 续接入口与模板持久化

- `next_entry` 是当前一次交接的导航入口，默认仅即时输出或写入获准的私有交付物。
- 包含真实项目路径、当前阶段、环境状态或私有计划位置的入口，不得默认写入仓库公共文档作为通用模板。
- 需要复用模板时，必须得到明确授权，并生成参数化模板；模板不得携带本次任务的具体路径、状态或隐私线索。

## 文档根目录判定

- 交付物属于研发过程材料，只写入项目规则确认的研发文档根目录。
- 轻量结束日志写入 `<authorized_rnd_docs_root>/记录文档/会话日志/`，详细交付物写入 `<authorized_rnd_docs_root>/记录文档/上下文交付物/`。
- 仓库即项目根且研发产出物需与公开内容隔离时，结束日志写入 `Project/Docs/记录文档/会话日志/`，详细交付物写入 `Project/Docs/记录文档/上下文交付物/`。
- 项目本身以 `Docs/` 管理研发产出物时，结束日志写入 `<project>/Docs/记录文档/会话日志/`，详细交付物写入 `<project>/Docs/记录文档/上下文交付物/`。
- 不得将具体会话交付物写入面向外部的仓库公开文档区域；公开文档只可承载经授权、参数化且无本次任务状态的模板。

## 交互能力适配

需要用户选择或授权时：
1. 检查本轮工具目录或宿主接口是否暴露支持所需题型的原生交互候选。
2. 已暴露匹配候选 → 必须先实际调用；成功呈现控件后记录 `interaction_mode: native_tool`。
3. 未暴露候选，或真实调用返回拒绝、不可用、不支持多选/题量 → 输出单个文本 `ClarificationRequest`，记录 `native_tool_candidate`、`native_tool_status`、`fallback_reason` 与 `capability_evidence`。
4. 不得以普通 Markdown 选项替代一个可用但未调用的原生选择工具。
5. 原生或文本降级的选项都必须包含推荐标识和核心逻辑理由；多选题可推荐组合。

## 自改边界

执行中发现 skill 不覆盖某场景时，只输出证据与改进候选。修改规则属于另一个已授权的迭代任务，不由本次会话交付自动发生。
